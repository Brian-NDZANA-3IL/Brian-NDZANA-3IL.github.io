Projet perso

Agent de support client par e-mail

Un agent qui trie les e-mails du service client, cherche la réponse dans la base de connaissances interne et prépare un brouillon avec ses sources. Une personne relit et valide chaque réponse : l'agent n'envoie rien lui-même.

  • Tri par catégorie et urgence avec Claude (sorties structurées Pydantic), recherche TF-IDF dans la base
  • Remboursements, gestes commerciaux et litiges exclus par double contrôle (modèle + règles), résistant aux tentatives de manipulation
  • Lecture IMAP en lecture seule, brouillons déposés dans la boîte, aucun code d'envoi
  • Interface de relecture Streamlit qui mesure les critères de succès : 60 % de brouillons sans modification majeure, 30 % de temps gagné
